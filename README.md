# 테트리스 — 한 줄씩, 가볍게.

PC 키보드와 모바일 터치 버튼으로 즐기는 테트리스 MVP입니다. Material UI 기본 컴포넌트와 반응형 화면, Web Audio API로 합성하는 코로베이니카 BGM을 제공합니다. 별도로 직접 작성한 CSS는 사용하지 않습니다.

랜딩 페이지는 `index.html`, 게임 화면은 `game.html`입니다. 각 HTML에 실행에 필요한 라이브러리와 코드가 포함되어 있어 **플레이할 때는 패키지 설치나 빌드가 필요하지 않습니다.** 두 파일을 같은 폴더에 보관하면 PC 브라우저에서 인터넷 연결 없이 랜딩과 게임을 오갈 수 있습니다.

## 가장 간단한 실행 방법

1. 프로젝트 폴더의 [index.html](index.html)을 찾습니다.
2. 파일을 더블클릭하거나, 실행 중인 브라우저 창으로 끌어다 놓습니다. 더블클릭했을 때 편집기가 열리면 **연결 프로그램**에서 브라우저를 선택합니다.
3. 랜딩 페이지에서 플레이 방법을 확인하고 **플레이** 버튼을 누릅니다.
4. `game.html#play`로 이동하면서 게임이 바로 시작됩니다.

브라우저 주소창에 `file:///.../index.html` 형태의 주소가 표시되면 파일에 직접 접속한 것입니다. 인터넷 연결이나 별도 서버가 필요하지 않습니다. `game.html`만 직접 열면 대기 화면이 나타나며 **게임 시작** 버튼으로 시작할 수 있습니다. JavaScript와 Canvas를 지원하는 브라우저를 사용하세요.

## 로컬 서버로 실행하고 접속하기 — 선택 사항

HTTP 주소로 접속하고 싶다면 Python 3의 기본 서버를 사용할 수 있습니다. 터미널에서 `index.html`이 있는 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows에서 `python3` 명령이 없다면 다음 명령을 사용할 수 있습니다.

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

서버를 실행한 컴퓨터의 브라우저에서 다음 주소로 접속합니다.

**[http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html)**

게임 화면에 직접 접속하려면 **[http://127.0.0.1:8000/game.html](http://127.0.0.1:8000/game.html)**을 엽니다.

- 플레이하는 동안 서버를 실행한 터미널을 열어둡니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.
- 8000번 포트를 이미 사용 중이라면 명령의 포트를 `8001`로 바꾸고, 접속 주소의 포트도 `8001`로 바꿉니다.
- 원격 개발 환경에서는 서버가 실행되는 환경의 8000번 포트를 전달한 뒤, 해당 환경에서 제공하는 전달 URL로 접속합니다. `127.0.0.1`은 브라우저가 실행되는 컴퓨터 자체를 가리킵니다.

## 휴대폰에서 접속하기

1. PC와 휴대폰을 같은 Wi-Fi에 연결합니다.
2. PC에서 `index.html`, `game.html`이 있는 폴더로 이동한 뒤 다음 명령으로 서버를 실행합니다. 기존 서버가 실행 중이면 `Ctrl+C`로 종료한 뒤 실행합니다.

   ```bash
   python3 -m http.server 8000 --bind 0.0.0.0
   ```

   Windows에서는 `python3` 대신 `py`를 사용할 수 있습니다.

3. PC의 Wi-Fi IPv4 주소를 확인합니다. Windows는 `ipconfig`, Linux는 `hostname -I`, macOS는 네트워크 설정에서 확인할 수 있습니다.
4. 휴대폰 브라우저에서 `http://PC의_IP주소:8000/index.html`로 접속합니다. 예를 들어 PC의 주소가 `192.168.0.10`이면 `http://192.168.0.10:8000/index.html`입니다.
5. **플레이**를 누른 뒤 게임판 아래의 터치 버튼으로 조작합니다. 가로 모드에서는 게임판 옆에 조작 버튼을 배치합니다.

휴대폰의 `127.0.0.1`은 PC를 가리키지 않으므로 PC의 실제 Wi-Fi 주소를 사용합니다. 가상머신·WSL·원격 개발 환경에서는 해당 환경의 포트 전달이나 외부 접속 설정이 필요할 수 있습니다. HTML 두 파일을 정적 웹 호스팅에 올린 경우에는 해당 사이트 주소로 접속할 수도 있습니다.

## 조작 방법

| PC 키보드 | 모바일 화면 버튼 | 동작 |
| --- | --- | --- |
| `←` / `→` | 왼쪽 / 오른쪽 화살표 | 블록 좌우 이동. 길게 누르면 반복 이동 |
| `↑` | 회전 화살표 | 블록 회전 |
| `↓` | 아래 화살표 | 빠르게 한 칸 내리기. 길게 누르면 반복 낙하 |
| `Space` | 즉시 떨어뜨리기 | 즉시 낙하 |
| `P` | 일시정지 / 계속하기 | 일시정지 / 재개 |
| — | 게임 시작 | 대기 화면에서 게임 시작 |
| — | 다시 시작 | 게임판과 점수를 초기화하고 새 게임 시작 |

모바일 화면 크기와 방향에 맞춰 게임판 크기를 조절합니다. 가로·세로 방향을 바꿔도 진행 중인 게임은 유지됩니다. 화면의 **플레이 방법** 링크를 누르면 랜딩 페이지의 조작 설명으로 돌아갑니다.

레벨 1에서 블록은 0.7초마다 자동으로 내려옵니다. 누적 10줄마다 레벨이 1씩 올라가고 낙하 간격이 60ms씩 줄어들며, 최소 간격은 100ms입니다. 현재 레벨은 점수 옆에 표시되고 재시작하면 레벨 1로 초기화됩니다. 한 번에 1·2·3·4줄을 제거하면 각각 100·300·500·800점을 얻습니다. 창을 벗어나거나 탭을 전환하면 자동으로 일시정지하며, 돌아온 뒤 **계속하기** 버튼이나 `P` 키로 재개할 수 있습니다.

새 블록이 들어올 공간이 없으면 게임이 종료됩니다. **다시 도전하기** 버튼으로 새 게임을 시작할 수 있습니다. 점수는 별도로 저장되지 않습니다.

## 배경음악

- 랜딩의 **플레이**로 입장하면 게임은 바로 시작하고, 게임 화면에서 첫 터치 또는 키보드 조작 후 코로베이니카가 반복 재생됩니다. 이는 새 페이지에서 음악을 자동 재생하는 브라우저 제한을 따르기 위한 동작입니다.
- `game.html`을 직접 열고 **게임 시작**을 누르면 게임과 음악이 함께 시작됩니다. 랜딩 페이지에서는 음악을 재생하지 않습니다.
- **배경음악** 패널의 스위치로 음악만 켜거나 끌 수 있습니다. 모바일에서는 패널 제목을 눌러 펼칩니다. 기본값은 켜짐이며 볼륨은 25%입니다.
- 볼륨 슬라이더로 0~100%를 조절합니다. 0%는 음소거입니다. 슬라이더는 키보드 방향키로도 조절할 수 있습니다.
- 게임을 일시정지하거나 창을 벗어나면 음악도 멈춥니다. 계속하기를 누르면 같은 위치에서 이어지고, 게임을 재시작하면 곡도 처음부터 시작합니다.
- 게임이 종료되면 음악도 멈춥니다. Web Audio를 지원하지 않거나 음악 재생이 차단된 환경에서도 게임은 실행할 수 있습니다.

외부 음원 파일을 다운로드하지 않고 Web Audio의 오실레이터로 멜로디와 베이스를 직접 합성합니다.

## 소스 수정 및 HTML 재생성 — 개발용

GitHub 계정 `YangSeungYeol`의 `tetris` 저장소에 배포하려면 [GITHUB_PAGES.md](GITHUB_PAGES.md)의 폴더 복사·Git 연동·Pages 설정 절차를 참고하세요.

플레이에는 이 과정이 필요하지 않습니다. 소스를 수정하려면 Node.js 18 이상과 npm이 설치된 환경에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다.

```bash
npm ci
npm run build
```

`npm ci`는 개발에 필요한 패키지를 내려받으므로 인터넷 연결이 필요합니다. 빌드가 끝나면 프로젝트 루트의 `index.html`과 `game.html`이 갱신됩니다. 두 파일을 같은 폴더로 복사하면 라이브러리 파일 없이 오프라인에서 실행할 수 있습니다.

`index.html`과 `game.html`은 생성 파일입니다. 랜딩은 `src/landing.jsx`, 게임 화면은 `src/app.jsx`, 게임 규칙은 `src/game.js`, 음악은 `src/bgm.js`를 수정한 뒤 다시 빌드하세요. UI는 [Material UI 공식 컴포넌트](https://mui.com/material-ui/getting-started/installation/)와 기본 테마를 사용하며, `sx`, 인라인 스타일, 직접 작성한 스타일시트는 추가하지 않습니다. 라이브러리가 생성하는 스타일은 HTML 실행 시 자동 적용됩니다.

## 테스트 실행 — 개발용

게임 실행에는 Node.js가 필요하지 않습니다. 게임·BGM·반응형 크기·터치 반복 입력 테스트를 실행할 때만 Node.js 18 이상을 사용합니다. 프로젝트 폴더에서 다음 명령을 실행합니다. 테스트 자체에는 npm 패키지 설치가 필요하지 않습니다.

```bash
node --test tests/bgm.test.mjs tests/tetris.test.mjs tests/input.test.mjs
```
